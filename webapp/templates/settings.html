About

Customer Review Sentiment classifies product reviews as positive, neutral, or negative using TF-IDF text features and a Logistic Regression classifier (see src/train.py). This Flask dashboard is one of three ways to use it — the others are a Streamlit dashboard (dashboard/app.py) and a REST API (app/main.py, FastAPI). Everything runs locally; nothing leaves this machine.
